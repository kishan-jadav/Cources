Google Map - Events

  • Map par click karein → us jagah ek naya marker add hoga
  • London wale marker ko drag karein → drag khatam hone par nayi position neeche dikhegi
  • London wale marker par mouse le jaayein → Info Window khulegi (mouseover / mouseout)
  • Map ko zoom in/out karein → current zoom level neeche update hoga
